# qmas-generate-ui-to-figma

Managed store for the QMAS **Generate UI → Figma** workflow skill (the orchestration layer that
turns a Claude-designed HTML/artifact into Figma frames). Works together with `qmas-design-system`.

- **Latest (stable):** [qmas-generate-ui-to-figma-latest.skill](https://github.com/marconip2023/qmas-generate-ui-to-figma/raw/main/qmas-generate-ui-to-figma-latest.skill)
- **v3:** [qmas-generate-ui-to-figma-v3.skill](https://github.com/marconip2023/qmas-generate-ui-to-figma/raw/main/qmas-generate-ui-to-figma-v3.skill)

A `.skill` file is just a zip. Install via Claude → Settings → Capabilities → Skills → Upload skill.
